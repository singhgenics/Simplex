# Simplex

The Betalbatim pub (South Goa) laid out without the loft or stair: one double-height room in a 4.5 × 4.5 × 10.5 m shell, 28 covers (20 inside, 8 in the beer garden). The menu, cuisine and look are the same as the loft version.

Live: https://singhgenics.github.io/Simplex/

| Page | What it is |
|---|---|

| [`model.html`](model.html) | Interactive 3D model (three.js) with zone cards, sizes and lighting controls |
| [`plan.html`](plan.html) | Dimensioned ground-floor plan |
| [`plans/`](plans/) | The plan as SVG and as a 3430 × 5550 px PNG |

Concept drawings for briefing an architect and a kitchen consultant, not for construction.
